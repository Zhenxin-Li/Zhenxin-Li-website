Are Household Incomes Keeping Up With Grocery Prices?

Relative prices and food purchasing power in the United States, 2015–2024

inflation
household-economics
Author

Zhenxin Li

Published

October 6, 2026

Higher grocery bills do not automatically mean that food has become more expensive relative to other goods, or that incomes buy less food. Those comparisons require a benchmark. This post asks: How did U.S. grocery prices change relative to overall consumer prices and median household income between 2015 and 2024, and how does the answer differ since 2020?

I use monthly, seasonally adjusted BLS consumer price indexes and annual Census median household income in current dollars. The code first tries FRED and, if unavailable, downloads from the official BLS API and Census H-5 table. Each saved series records its actual source; the Census fallback uses published rounded current-dollar values. Monthly indexes are averaged within each calendar year; 2014 observations supply the twelve-month lag for 2015 inflation. All annual comparisons end in 2024. The code saves downloads and calculated results, checks for missing months, and reuses saved data on subsequent renders.

A higher grocery bill is not the same as a higher relative price

Figure 1 measures the food-at-home CPI divided by the all-items CPI, normalized to 100 in 2015:

\[ R_t=100\frac{F_t/A_t}{F_{2015}/A_{2015}}. \]

Here, \(F_t\) and \(A_t\) are annual-average price indexes. A rise means groceries became more expensive relative to the broad consumer basket, which itself includes food. This ratio measures relative price movements, not the dollar price of one basket compared with another.

From 2015 to 2024, grocery prices increased by 26.5%, while overall prices increased by 32.4%. Consequently, the relative food-price ratio decreased by 4.4%. Over 2020–2024, that same ratio increased by 1.1%. The post-2020 experience therefore cannot stand in for the full decade. Changing an index’s normalization rescales the line; changing the comparison’s starting year changes the economic question. Percentage changes in the ratio between fixed endpoints are independent of normalization.

Slower inflation does not restore earlier prices

Food inflation peaked at 13.6% in 八月 2022 within this sample. Its subsequent decline describes disinflation: prices rose more slowly. Only a negative rate indicates falling prices relative to a year earlier. A lower inflation rate can therefore coexist with grocery bills well above their pre-surge levels.

The grocery basket contains different price experiences

Across these categories, cumulative increases range from 20.1% to 31.3%. Households buying different baskets can experience different pressures. These bars are unweighted category price changes, so they cannot identify which category contributed most to aggregate food inflation. Doing that would require expenditure weights.

How much food could median household income buy?

I deflate nominal median household income by the food CPI and normalize the resulting ratio to 100 in 2015. Using an already inflation-adjusted income series would adjust for prices twice.

\[ P_t=100\frac{Y_t/F_t}{Y_{2015}/F_{2015}}. \]

Food purchasing power increased by 16.3% over 2015–2024, compared with decreased by 0.2% over 2020–2024. This is a descriptive benchmark, not a paycheck measure or a household budget: household income includes sources beyond wages, and households differ in size, expenses, and income growth. The median can also change as household composition changes. These aggregates cannot establish that every household recovered, or that any loss was permanent or temporary beyond 2024.

Takeaway

The starting year matters. Grocery prices rose in dollars, but their relative price decreased by 4.4% over the full 2015–2024 window, versus increased by 1.1% since 2020. Food purchasing power likewise requires an explicit comparison period. Reading relative prices, inflation rates, and income together explains why easing inflation need not bring either lower grocery bills or the same experience for every household.

read_series <- function(path, id) {
  x <- readr::read_csv(path, na = c("", "."), show_col_types = FALSE)
  date_col <- intersect(c("observation_date", "DATE", "date"), names(x))
  if (length(date_col) != 1L || !id %in% names(x)) {
    stop("Invalid FRED CSV for ", id, "; the server may have returned an error page.")
  }
  out <- tibble(date = as.Date(x[[date_col]]), value = as.numeric(x[[id]])) |>
    filter(date >= as.Date("2014-01-01"), date <= as.Date("2024-12-31")) |>
    arrange(date)
  expected <- if (id == "MEHOINUSA646N") {
    seq(as.Date("2014-01-01"), as.Date("2024-01-01"), by = "year")
  } else seq(as.Date("2014-01-01"), as.Date("2024-12-01"), by = "month")
  if (!identical(out$date, expected) || any(!is.finite(out$value)) || any(out$value <= 0)) {
    stop("Incomplete, duplicate, or invalid observations for ", id)
  }
  out
}

# Official publisher fallback. Preserve original responses as well as normalized CSVs.
official_download <- function(id, destination) {
  needed <- if (id == "MEHOINUSA646N") "readxl" else "jsonlite"
  if (!requireNamespace(needed, quietly = TRUE)) {
    stop("Official-source fallback requires the R package '", needed, "'. Install it and retry.")
  }
  sources <- file.path(raw_dir, "sources")
  dir.create(sources, recursive = TRUE, showWarnings = FALSE)
  urls <- character()
  if (id == "MEHOINUSA646N") {
    url <- paste0("https://www2.census.gov/programs-surveys/cps/tables/",
                  "time-series/historical-income-households/h05.xlsx")
    original <- file.path(sources, "census_h05.xlsx")
    if (!file.exists(original)) download.file(url, original, mode = "wb", quiet = TRUE)
    tab <- readxl::read_excel(original, sheet = "h05", col_names = FALSE,
                             col_types = "text", .name_repair = "minimal")
    # Locate All Races, then select the Median income / Current dollars column.
    start <- which(trimws(tab[[1]]) == "All Races")[1]
    if (is.na(start)) stop("Census H-5 layout changed: All Races section missing.")
    median_col <- which(trimws(unlist(tab[start + 1L, ])) == "Median income")
    if (length(median_col) != 1L ||
        !grepl("Current", tab[[median_col]][start + 2L], fixed = TRUE)) {
      stop("Census H-5 layout changed: nominal median column not confirmed.")
    }
    # The current table puts the updated 2017 row before the legacy 2017 row.
    # Stop at the first 2014 row so other race groups cannot enter the sample.
    year_labels <- as.character(tab[[1]])
    end <- which(seq_len(nrow(tab)) > start & grepl("^2014($|[^0-9])", year_labels))[1]
    if (is.na(end)) stop("Census H-5 does not include 2014.")
    rows <- seq.int(start + 3L, end)
    years <- suppressWarnings(as.integer(substr(year_labels[rows], 1, 4)))
    out <- tibble(year = years, value = readr::parse_number(tab[[median_col]][rows])) |>
      filter(!is.na(year), year >= 2014, year <= 2024) |>
      distinct(year, .keep_all = TRUE) |>
      transmute(observation_date = as.Date(paste0(year, "-01-01")), value)
    urls <- url
  } else {
    bls_id <- if (id == "CPIAUCSL") "CUSR0000SA0" else id
    chunks <- lapply(list(c(2014, 2023), c(2024, 2024)), function(bounds) {
      url <- paste0("https://api.bls.gov/publicAPI/v2/timeseries/data/", bls_id,
                    "?startyear=", bounds[1], "&endyear=", bounds[2])
      original <- file.path(sources, paste0(bls_id, "_", bounds[1], "_", bounds[2], ".json"))
      if (!file.exists(original)) download.file(url, original, mode = "wb", quiet = TRUE)
      response <- jsonlite::fromJSON(original, simplifyVector = FALSE)
      if (!identical(response$status, "REQUEST_SUCCEEDED") ||
          length(response$Results$series) != 1L ||
          response$Results$series[[1]]$seriesID != bls_id) stop("Invalid BLS API response for ", bls_id)
      urls <<- c(urls, url)
      bind_rows(lapply(response$Results$series[[1]]$data, function(row) {
        if (!row$period %in% sprintf("M%02d", 1:12)) return(NULL)
        tibble(observation_date = as.Date(paste0(row$year, "-", substr(row$period, 2, 3), "-01")),
               value = as.numeric(row$value))
      }))
    })
    out <- bind_rows(chunks)
  }
  out <- arrange(out, observation_date)
  names(out)[2] <- id
  write_csv(out, destination)
  read_series(destination, id)
  c("Acquisition: official publisher fallback (not a FRED download)",
    paste0("URL: ", urls),
    if (id == "MEHOINUSA646N")
      "Census H-5: All Races, Median income, Current dollars; first (updated) row per year. Published rounded values."
    else paste0("BLS series: ", bls_id))
}

get_series <- function(id) {
  path <- file.path(raw_dir, paste0(id, ".csv"))
  if (!file.exists(path)) {
    url <- paste0("https://fred.stlouisfed.org/graph/fredgraph.csv?id=", id,
                  "&cosd=2014-01-01&coed=2024-12-31")
    tmp <- tempfile(fileext = ".csv")
    on.exit(unlink(tmp), add = TRUE)
    provenance <- tryCatch({
      download.file(url, tmp, mode = "wb", quiet = TRUE)
      read_series(tmp, id) # Validate before saving; never cache maintenance pages.
      c("Acquisition: FRED CSV", paste0("URL: ", url))
    }, error = function(e) {
      message("FRED unavailable for ", id, "; trying the official publisher.")
      tryCatch(official_download(id, tmp), error = function(fallback_error) {
        stop("Cannot obtain ", id, ". FRED: ", conditionMessage(e),
             " Official publisher: ", conditionMessage(fallback_error))
      })
    })
    if (!file.copy(tmp, path)) stop("Cannot save raw data: ", path)
    writeLines(c(paste0("Retrieved UTC: ", format(Sys.time(), tz = "UTC", usetz = TRUE)),
                 provenance), paste0(path, ".source.txt"))
  }
  read_series(path, id) |>
    mutate(series_id = id, series = unname(series[id]))
}
monthly <- bind_rows(lapply(names(series), get_series))
price_data <- monthly |> filter(series_id != "MEHOINUSA646N")
annual <- price_data |>
  mutate(year = as.integer(format(date, "%Y"))) |>
  group_by(series_id, series, year) |>
  summarise(n_months = n(), cpi = mean(value), .groups = "drop")
stopifnot(all(annual$n_months == 12L))
annual <- annual |> filter(year >= 2015)

main <- annual |> filter(series_id %in% c("CUSR0000SAF11", "CPIAUCSL")) |>
  select(year, series_id, cpi) |> pivot_wider(names_from = series_id, values_from = cpi) |>
  rename(food = CUSR0000SAF11, overall = CPIAUCSL) |> arrange(year) |>
  mutate(relative = (food / overall) / (food[year == 2015] / overall[year == 2015]) * 100)
income <- monthly |> filter(series_id == "MEHOINUSA646N") |>
  transmute(year = as.integer(format(date, "%Y")), income = value) |> filter(year >= 2015)
main <- left_join(main, income, by = "year") |>
  mutate(power = (income / food) / (income[year == 2015] / food[year == 2015]) * 100)
stopifnot(nrow(main) == 10L, !anyNA(main))
endpoint <- function(x, base) 100 * (x[main$year == 2024] / x[main$year == base] - 1)
comparison <- bind_rows(lapply(c(2015, 2020), function(b) tibble(
  period = paste0(b, "-2024"), food_pct = endpoint(main$food, b),
  overall_pct = endpoint(main$overall, b), relative_pct = endpoint(main$relative, b),
  income_pct = endpoint(main$income, b), food_power_pct = endpoint(main$power, b)
)))
pct <- function(x) sprintf("%.1f%%", x)
change_words <- function(x) paste(if (x >= 0) "increased by" else "decreased by", pct(abs(x)))
full <- comparison[1, ]; recent <- comparison[2, ]
inflation <- price_data |> filter(series_id == "CUSR0000SAF11") |> arrange(date) |>
  mutate(yoy = 100 * (value / lag(value, 12) - 1)) |> filter(date >= as.Date("2015-01-01"))
stopifnot(nrow(inflation) == 120L, !anyNA(inflation$yoy))
peak <- inflation |> slice_max(yoy, n = 1, with_ties = FALSE)
categories <- annual |> filter(!series_id %in% c("CUSR0000SAF11", "CPIAUCSL")) |>
  group_by(series_id, series) |>
  summarise(change_pct = 100 * (cpi[year == 2024] / cpi[year == 2015] - 1), .groups = "drop")
write_csv(annual, file.path(results_dir, "annual_cpi.csv"))
write_csv(main, file.path(results_dir, "relative_prices_and_purchasing_power.csv"))
write_csv(comparison, file.path(results_dir, "period_comparison.csv"))
write_csv(inflation, file.path(results_dir, "monthly_food_inflation.csv"))
write_csv(categories, file.path(results_dir, "category_changes.csv"))
writeLines(capture.output(sessionInfo()), file.path(results_dir, "sessionInfo.txt"))
